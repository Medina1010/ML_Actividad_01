# Actividad_01 Maching Learning
En este repositorio se encuentra la [actividad 1](actividad_01.md) con el [codigo](text_gen.c) realizado para esta.

Se incluye una libreria personal de manejo de texto [formater.h](formater.h).

Ademas de un miniprograma de ejecución [bld.c](bld.c), solo hay que compilarlo
``` sh
gcc -o bld bld.c
```
y correrlo para compilar y ejecutar los codigos y graficas
``` sh
./bld
```
